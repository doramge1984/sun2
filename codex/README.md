# 순천대 AI 팀 빌딩 웹교안

코덱스(Codex)로 "내 업무 설명 → 에이전트·총괄 설계 → 직접 만들기 → 더미 데이터로 일 시키기 → 대시보드 보고 → 사람 승인"을 실습하는 웹교안입니다. (국립순천대 제조기업 재직자 AI 연수, 코덱스 파트)

## 구성
- `index.html` : 교안 본문 (공정 1~6 + 막혔을 때)
- `images/` : 화면 예시 이미지 (토글 안에서 표시)
- `downloads/ai-team-starter.zip` : 수강생 시작 폴더 (순천정밀_AI팀_시작폴더: 기준자료, 예시본)

## GitHub Pages
저장소 설정의 Pages에서 이 폴더를 배포하면 `index.html`이 열립니다. 모든 경로는 상대 경로입니다.

## 주의
- 모든 회사명·수치·파일은 교육용 가상 자료입니다.
- 코덱스의 사용자 지정 에이전트(.codex/agents) 인식 방식은 앱 버전에 따라 다를 수 있으니, 교육 전 강사 PC에서 한 번 시험해 보세요.
